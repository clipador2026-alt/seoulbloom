# Seoul Bloom 🌸

Novo blog de doramas e cultura coreana. Domínio oficial planejado: https://seoulbloom.me

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar versão estática

```bash
npm run build
```

O Next.js cria a pasta `out/`, preparada para hospedagem de arquivos estáticos. A Vercel será usada para testes; a Hostinger receberá a versão final quando aprovada.

## Publicar artigos

Por enquanto, os artigos são mantidos em `lib/posts.ts`. O painel editorial ainda não foi implementado. Atualize e revise os conteúdos antes de publicar.

## Antes do lançamento e do AdSense

- Adicionar endereço de contato real.
- Revisar Política de Privacidade, consentimento e práticas de cookies.
- Publicar mais conteúdo original e verificar fontes e direitos de imagem.
- Testar o build, links, layout móvel e implantação.
- Configurar Search Console e solicitar aprovação do AdSense somente quando o site estiver pronto.
